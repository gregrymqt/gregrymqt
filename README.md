### 💻 Projetos em Destaque

#### [Greg Company Ecosystem](https://github.com/gregrymqt/greg-company-ecosystem)
> Plataforma de e-commerce e cursos online

| | |
|---|---|
| **O Problema** | Plataformas de e-commerce monolíticas apresentam alto acoplamento entre domínios de negócio, dificultando a evolução independente de funcionalidades e a troca de banco de dados sem reescrita de código. |
| **A Solução** | Arquitetura orientada a **Vertical Slice**, onde cada feature é auto-contida (handler, contrato e acesso a dados no mesmo módulo). Suporte a **múltiplos bancos de dados** (multi-database) via abstração de repositório, e **Redis** como camada de cache distribuído para reduzir latência em leituras frequentes. |

`C#` · `.NET` · `React (TypeScript)` · `SQL Server` · `Redis` · `Docker` · `Vertical Slice Architecture`

#### [Usafa](https://github.com/gregrymqt/Usafa)
> Sistema de agendamento de consultas na rede pública de saúde

| | |
|---|---|
| **O Problema** | O agendamento de consultas na rede pública de saúde é frequentemente manual ou dependente de filas presenciais, gerando baixa adesão e desperdício de vagas disponíveis. |
| **A Solução** | Aplicação web completa que centraliza o agendamento de forma digital, com controle de disponibilidade por unidade de saúde e autenticação de pacientes, tornando o acesso mais eficiente e rastreável. |

`Java` · `Spring Boot` · `React` · `PostgreSQL`
